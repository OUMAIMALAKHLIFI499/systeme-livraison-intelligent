# Système de Livraison Intelligent

## Présentation du projet

Ce projet a été réalisé dans le cadre du module Systèmes Multi-Agents  du Master AI et Applications.

L’objectif est de développer un système de livraison intelligent en utilisant le framework JADE . Le système repose sur plusieurs agents qui communiquent et collaborent pour gérer les opérations de livraison.

## Technologies utilisées

- Langage : Java
- Framework SMA : JADE
- Environnement de développement : Eclipse

## Fonctionnalités

- Gestion des agents du système de livraison.
- Communication entre les agents à l’aide de JADE.
- Coordination des tâches liées à la livraison.

## Installation et exécution

1. Installer Java et Eclipse.
2. Configurer la bibliothèque JADE dans le projet Eclipse.
3. Importer le projet dans Eclipse.
4. Vérifier la configuration des agents.
5. Exécuter l’agent principal pour démarrer le système.
